# Recruiter Summary – Java Service Ticket API

## Kurzbeschreibung

Die Java Service Ticket API ist ein Bewerberprojekt für duale Studiengänge in Informatik und Wirtschaftsinformatik. Das Projekt simuliert eine einfache REST-Schnittstelle zur Verwaltung von IT-Service-Tickets und zeigt grundlegende Backend-Konzepte mit Java, Spring Boot, JPA, Validierung und Tests.

## Was das Projekt zeigt

- Java 21 und Spring Boot-Grundlagen
- REST-Endpunkte für einfache IT-Service-Prozesse
- Trennung von Controller, Service, Repository, DTO und Entity
- Bean Validation für Eingabedaten
- JPA Repository mit H2-Datenbank
- Unit Tests und Controller-Tests mit JUnit 5 und MockMvc
- GitHub Actions als CI-Grundlage
- Verständliche Dokumentation auf Bewerberniveau

## Bewerbungsbezug

Das Projekt eignet sich besonders für Bewerbungen im Bereich Informatik, Wirtschaftsinformatik, Backend-Entwicklung, Software Engineering und IT-Service-Prozesse. Es passt fachlich zu Unternehmen wie Atruvia, Finanz Informatik, Allianz, ConSol, CANCOM, Deutsche Telekom, Atos, Deloitte und EY.

## Wichtiger Hinweis

Die Anwendung ist ein Bewerberprojekt mit synthetischen Beispielen. Sie bildet kein echtes Ticketsystem und keine produktive Unternehmensinfrastruktur ab.
